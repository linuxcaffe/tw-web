# Keyboard shortcuts

## Navigation

| Key | Does |
|---|---|
| `L` | Task list |
| `K` | Kanban board |
| `A` | Agenda |
| `C` | Calendar |
| `N` | nb-web (when the `nb` annotation launcher is a web address) |
| `?` | Help |
| `Esc` | Focus the menu button (always: the way out of a filter input) |
| `Enter` on the menu button | Open the side menu |
| `↑` `↓` | Move through the menu items |
| `Esc` in the menu | Close the menu, back to the menu button |

## Task list

| Key | Does |
|---|---|
| `a` | Add a new task |
| `f` | Focus the filter input |
| `c` | Focus the context buttons |
| `s` | Focus the status buttons |

## Calendar

| Key | Does |
|---|---|
| `D` | Day view; again: next zoom step |
| `W` | Week view; again: next zoom step |
| `M` | Month view |
| `T` | Jump to today |
| `←` `→` | Previous / next day, week or month |
| `Space` | Repeat the view button last clicked (after Week or Day: next zoom step), until you click elsewhere |

More on the Calendar's zoom steps and phone gestures: [Calendar](tw-web/calendar.md).

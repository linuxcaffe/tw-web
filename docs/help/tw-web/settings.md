# Settings

**Menu → Settings**: notification timeout, Kanban columns, the Calendar's day range and default view, and more.

**`~/.task/config/tw-web.rc`**: Taskwarrior settings tw-web relies on: [UDAs](../taskwarrior/udas.md), [urgency](../taskwarrior/urgency.md) coefficients, the recurrence engine.

If something is missing or broken, check the browser console and the tw-web server log.
